# Definition of Done

> **Project:** Project Loom
>
> **Status:** Active (2026-08-07)
>
> **Purpose:** Criteria that must be satisfied before any phase is marked complete.

---

## Phase Completion Criteria

A phase is complete **only when** all of the following criteria are met:

| Criterion | Status | Verification |
|-----------|--------|--------------|
| ✅ Build passes | Required | `pnpm build` succeeds |
| ✅ Typecheck passes | Required | `pnpm typecheck` succeeds |
| ✅ Lint passes | Required | `pnpm lint` succeeds |
| ✅ Tests pass | Required | `pnpm test` succeeds |
| ✅ Documentation updated | Required | Relevant docs reflect changes |
| ✅ TASKS.md updated | Required | Current phase tasks checked |
| ✅ PROGRESS.md updated | Required | Milestone recorded |
| ✅ Completion report written | Required | Phase summary documented |

---

## Rule

**No phase may be marked complete until ALL criteria are satisfied.**
